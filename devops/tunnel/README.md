# Cloudflare Tunnel Configuration for Qrono Wireless Access
# This allows students to access the app from any device without router configuration

# =========================================
# CLOUDFLARE TUNNEL SETUP
# =========================================

# 1. Install cloudflared:
#    - Download from: https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/tunnel-guide/
#    - Or via package manager: npm install -g cloudflare/cloudflared

# 2. Authenticate with Cloudflare:
#    cloudflared tunnel login

# 3. Create tunnel:
#    cloudflared tunnel create qrono-tunnel

# 4. Get tunnel ID:
#    cloudflared tunnel list

# 5. Update config.yaml with your tunnel ID and domain

# 6. Route traffic:
#    cloudflared tunnel route dns qrono-tunnel your-subdomain.yourdomain.com

# 7. Run tunnel:
#    cloudflared tunnel run qrono-tunnel

# =========================================
# CONFIGURATION FILES
# =========================================

# config.yaml - Main tunnel configuration
# credentials.json - Auto-generated by cloudflared login

# =========================================
# USAGE
# =========================================

# Start tunnel: ./start-tunnel.sh
# Stop tunnel: ./stop-tunnel.sh
# Check status: ./status-tunnel.sh

# =========================================
# SECURITY NOTES
# =========================================

# - Never commit credentials.json to git
# - Use HTTPS for all connections
# - Configure proper CORS in backend
# - Consider rate limiting for production
