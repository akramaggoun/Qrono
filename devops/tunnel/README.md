# Cloudflare Tunnel Configuration for Qrono Wireless Access
# This allows students to access the app from any device without router configuration

# =========================================
# AUTOMATED SETUP (RECOMMENDED)
# =========================================

## One-Command Setup (Windows)
```cmd
cd devops\tunnel
setup-tunnel.bat
```

## One-Command Setup (Linux/Mac)
```bash
cd devops/tunnel
./setup-tunnel.sh
```

The automated script will:
- ✅ Check prerequisites
- ✅ Handle Cloudflare authentication
- ✅ Create and configure the tunnel
- ✅ Set up DNS routing
- ✅ Update configuration files
- ✅ Provide final setup instructions

# =========================================
# MANUAL SETUP (Advanced Users)
# =========================================

## 1. Install cloudflared:
#    - Download from: https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/tunnel-guide/
#    - Or via package manager: npm install -g cloudflare/cloudflared

## 2. Authenticate with Cloudflare:
#    cloudflared tunnel login

## 3. Create tunnel:
#    cloudflared tunnel create qrono-tunnel

## 4. Get tunnel ID:
#    cloudflared tunnel list

## 5. Update config.yaml with your tunnel ID and domain

## 6. Route traffic:
#    cloudflared tunnel route dns qrono-tunnel your-subdomain.yourdomain.com

## 7. Run tunnel:
#    cloudflared tunnel run qrono-tunnel

# =========================================
# STUDENT APP CONFIGURATION
# =========================================

After tunnel is running:
1. Students open Qrono app
2. Go to Settings (⚙️ icon in top right)
3. Select "Wireless (Cloudflare Tunnel)"
4. Enter the tunnel URL shown in setup completion
5. Apply settings and restart app
6. Students can now scan QR codes from anywhere! 📱✨
